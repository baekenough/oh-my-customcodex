# External Interop Guidance

Packaged provider wrapper skills have been retired. Use the official Claude Code plugin `openai/codex-plugin-cc` only when it is explicitly installed and requested. Otherwise prefer existing expert agents, `researcher` paths, `roundtable-debate`, or `rtk-exec` for token-optimized command output.
