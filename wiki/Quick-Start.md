# Quick Start

## Installation

```bash
# Install globally
npm install -g oh-my-customcodex

# Initialize in your project
cd your-project
omcustomcodex init
```

That's it. You now have a fully configured Claude Code environment.

## Language Options

```bash
# English (default)
omcustomcodex init

# Korean
omcustomcodex init --lang ko
```
