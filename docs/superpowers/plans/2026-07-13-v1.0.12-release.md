# v1.0.12 Release Plan

## Goal

Make active model routing and Web generation native to GPT Codex plus OMX instead of silently retaining Claude-first metadata and process paths.

## Release Unit

| Issue | Priority | Outcome |
| --- | --- | --- |
| #1593 | P1 | Resolve provider-neutral agent lanes and native reasoning effort from the current Codex/OMX runtime contract across generated TOML, Web UI, eval, ontology, and active guidance. |
| #1598 | P1 | Use Codex as the primary Web generator for agents, skills, and guides, with explicit Claude compatibility and keyword fallbacks. |

## Constraints

- Preserve the parent-package source and compatibility shape while making Codex/OMX the active provider boundary.
- Do not hardcode repository-local model aliases as universal runtime defaults.
- Keep Claude aliases only in explicit compatibility sources and normalization boundaries.
- Never construct shell command strings from Web generation requests.
- Bound provider execution time and output, isolate provider working directories, and expose truthful fallback diagnostics.

## Implementation

1. Represent native agent intent with `model_lane` plus `model_reasoning_effort` and compile concrete TOML models from the installed OMX resolution contract.
2. Align active documentation, eval recommendations, ontology metadata, and Web model controls with the same lane and effort vocabulary.
3. Replace the Claude-only Web helper with one argv-based provider abstraction ordered Codex, Claude compatibility, then keyword fallback.
4. Exercise Codex-only agent, skill, and guide creation plus provider priority, failure diagnostics, timeout, and output limits with hermetic fake executables.

## Verification

- Targeted compiler, template, eval, ontology, Serve provider, and three-route generation tests.
- Root lint, TypeScript checks, Serve checks, documentation build, full tests, production build, and package-contract verification.
- PR checks green, merge to `develop`, tag `v1.0.12`, npm/GitHub Packages publication, GitHub Release, issue/milestone closure, and clean registry-install smoke (R020).

## Stop Condition

The release is complete only when both registries expose `1.0.12`, the tag and GitHub Release resolve to the merged commit, a clean packed install validates Codex/OMX native model and Web generation surfaces, #1593 and #1598 plus the v1.0.12 milestone are closed, and the remote release branch is removed.
