# v1.0.31 FSD Retrospective Hardening Plan

## Scope

Resolve #1686 without redesigning the upstream-compatible release harness:

1. Make `omcustomcodex update --hooks` a safe source-checkout bootstrap.
2. Keep source lockfile generation byte-idempotent when its semantic snapshot is unchanged.
3. Separate remote PR merge from remote branch cleanup in linked/multi-worktree releases.
4. Ignore data-only heredoc bodies and ordinary quoted data in shell advisory matching without hiding heredocs executed by a shell.

## Behavior Locks

- Source projects still reject normal self-update components.
- A hooks-only source bootstrap writes only runtime registry/compatibility metadata and never copies or deletes tracked hook assets.
- A linked release worktree resolves hook assets from the authoritative checkout and leaves that checkout's tracked hook tree byte-identical.
- Repeated lockfile generation preserves `generatedAt` only when every other lockfile field is deeply equal; semantic changes receive a new timestamp.
- A linked source snapshot hashes the release candidate's hook bytes without recording runtime-root indirection or machine-local registry metadata.
- Release guidance never couples `gh pr merge` to local branch cleanup with `--delete-branch`; it reads back `MERGED` plus the merge SHA before deleting only the remote ref through the GitHub API.
- Advisory sanitization strips data-only quoted heredoc bodies and ordinary quoted literals, while retaining heredocs supplied to `bash`/`sh`/`zsh` and quoted payloads passed through shell `-c` or `eval`.

## Test-First Sequence

1. Add focused failing tests for source checkout and linked-worktree hook preservation.
2. Add lockfile byte-idempotency and semantic-change timestamp tests.
3. Add workflow contract assertions for merge/readback/remote-ref cleanup and the post-freeze mutation ban.
4. Add standalone and Codex-native advisory cases for heredoc/search literals plus nested shell execution.
5. Implement the smallest production changes and synchronize canonical/template/plugin copies.
6. Run targeted tests, then lint, typecheck, full tests, build, package/release contracts, R017, and exact-tree verification.

## Stop Condition

The release tree is clean and frozen, all verification gates pass, #1686 closes through the v1.0.31 automation, both registries and the GitHub Release read back v1.0.31, and the eligible issue/PR queues return zero after homework.
