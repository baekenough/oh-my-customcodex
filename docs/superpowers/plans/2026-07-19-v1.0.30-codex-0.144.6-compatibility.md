# v1.0.30 Codex 0.144.6 호환성 기록 계획

> 생성일: 2026-07-19
> 기준 커밋: `a16a15546cb1813cd7bb78587ad06385d2d466c6` (`v1.0.29`)
> 대상 이슈: #1683

## 목표

OpenAI Codex `rust-v0.144.6`의 GPT-5.6 Sol/Terra/Luna 번들 지침 갱신과 272,000-token context-window 교정을 공식 호환성 기록에 반영한다. 모델 프롬프트와 context-window 메타데이터는 Codex runtime 소유이므로 이 child package에 상수나 프롬프트를 복제하지 않는다.

## 직접 근거

- 공식 release note는 GPT-5.6 Sol/Terra/Luna의 bundled instructions를 갱신하고 context window를 272,000 tokens로 교정했다고 명시한다.
- `rust-v0.144.5...rust-v0.144.6` 비교는 `codex-rs/models-manager/models.json`과 release version metadata만 변경한다.
- 현재 포트는 모델 lane을 Codex/OMX runtime 설정에서 해석하며 package-owned context-window 상수나 model-manager 구현을 갖지 않는다.

## 변경 범위

1. `guides/openai-codex/01-version-compatibility.md`에 `rust-v0.144.6` final-state 결정을 추가한다.
2. `templates/guides/openai-codex/01-version-compatibility.md`를 canonical guide와 byte-identical하게 유지한다.
3. `wiki/guides/openai-codex.md` current release note와 source hash를 동기화한다.
4. 기존 template-validation 회귀 테스트를 확장해 `rust-v0.144.6`, `272,000`, `#1683`, provider-owned 비복제 결정을 잠근다.
5. package/template/plugin/lockfile을 `1.0.30`으로 승격하고 changelog를 작성한다.

## 비변경 결정

- Codex 최소 버전을 추가하지 않는다. 패키지는 특정 Codex 버전을 설치·관리하지 않으며 model metadata API 계약도 소유하지 않는다.
- GPT-5.6 bundled prompt 또는 272,000 상수를 runtime 설정에 복제하지 않는다.
- OMX model routing table을 변경하지 않는다. 이번 release는 Codex model-manager의 metadata correction이며 OMX lane 선택 변경이 아니다.

## 테스트 우선 순서

1. 기존 호환성 테스트에 새 계약을 추가하고 실패를 확인한다.
2. source/template/wiki를 구현하고 targeted test를 통과시킨다.
3. version/changelog와 생성물을 동기화한다.
4. lint, typecheck, build, package/offline contract, 전체 테스트, docs/template/wiki sync를 검증한다.
5. R017 review 후 PR을 병합하고 tag/npm/GitHub Packages/GitHub Release를 R020으로 확인한다.
